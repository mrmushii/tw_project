# Presentation & report figures

Generated by `scripts/04_presentation_figures.py` from the same two prediction CSVs
that `03_compare_results.py` uses, with the same basename alignment — so these
figures cannot drift from the reported numbers. Re-run after any prediction change:

```
python scripts/04_presentation_figures.py          # light surface -> results/figures/
python scripts/04_presentation_figures.py --dark   # dark surface  -> results/figures/dark/
```

Two series throughout: **blue = Claude agent (zero-shot)**, **orange = VGG-16
(fine-tuned)**. The pair is colourblind-safe on both surfaces.

| File | Shows | Use it for |
|---|---|---|
| `fig1_headline.png` | accuracy + macro-F1, McNemar p in the subtitle | the headline slide — leads with the tie, not with "the agent won" |
| `fig2_per_class_f1.png` | per-class F1, both branches | shows neither branch dominates across all six classes |
| `fig3_per_class_delta.png` | per-class recall gap, agent − VGG-16 | the class-level split the overall tie hides (buildings −19%, street +14%) |
| `fig4_outcome_breakdown.png` | 184 both-right / 14 agent-only / 11 VGG-only / 7 both-wrong | the oracle bound (96.8%) and how few images defeat both |
| `fig5_error_asymmetry.png` | directional confusion counts | **the core finding** — agent errors are one-directional, VGG-16's are symmetric |
| `fig6_disagreement_grid.png` | eight real test images, both branches' calls | the qualitative slide; four each way, not cherry-picked |
| `fig7_tradeoff.png` | the qualitative trade-off table | the closing slide — same score, different cost/failure/extension |

`confusion_matrices.png` (from step 5) still stands on its own as the raw
per-class error view; `fig5` is the argument built on top of it.

These PNGs **are** committed (~5 MB), unlike `results/*.png` — the report and slides
need them, and `.gitignore` only excludes generated images at the top level of
`results/`. Re-run the script and commit the result rather than editing them.
